# zebot

Скилл для LLM-агентов, который размечает политические посты классами пропагандистского анализа канала [ZeBot2050](https://t.me/ZeBot2050) («Язык ненависти: Зеленский и другие»).

Аналитик ZeBot помечает цитаты Зеленского тегом и короткой формулировкой, например `мифологема: россия — мировое зло`. Скилл `zebot-classify` выбирает для поста **один класс из закрытого словаря или `null`**.

## Состав

| Путь | Что это |
|---|---|
| `skills/zebot-classify/SKILL.md` | Метод: шаги разметки, таблица признаков, правила выбора при конфликте, примеры |
| `skills/zebot-classify/vocab.md` | Словарь из 127 классов: мифологема 46, тема 45, месседж 19, цель 16, факт 1 |
| `scripts/validate.py` | Проверка ответов модели: формат JSON Lines, порядок id, класс дословно из словаря |

## Установка

Скопируйте папку `skills/zebot-classify` в каталог скиллов агента, например:

```bash
cp -r skills/zebot-classify ~/.claude/skills/   # Claude Code
cp -r skills/zebot-classify ~/.coddy/skills/    # Coddy
```

## Использование

На вход подаётся JSON Lines, по одному посту в строке:

```
{"id": "e2", "text": "Ночью россияне ударили по подстанциям в трёх областях. Без света остались 300 тысяч семей."}
```

На выходе тоже JSON Lines, по одной строке на пост, в том же порядке:

```
{"id": "e2", "class": "мифологема: россия воюет против мирного населения"}
```

Проверка ответа (нужен только Python 3, без зависимостей):

```bash
python3 scripts/validate.py posts.jsonl answers.jsonl
```

## Как проверялся

- **Кросс-ревью.** Метод проверили три ревьюера из разных семейств моделей. Вердикт — «одобрить с изменениями». Все 14 правок внесены в версию 1.1.0.
- **Согласие моделей.** Скилл прогнали на 1000 свежих постах канала Зеленского (июль–ноябрь 2026), переведённых на русский. 100 постов, по которым составлена таблица признаков, в расчёт не входят, метрики посчитаны на оставшихся 900:

| Пара | Совпадение класса | Каппа Коэна |
|---|---|---|
| Claude Opus и GPT-6.1 Sol, обе со скиллом | 79,8% (95% ДИ 77,1–82,2) | 0,77 |
| LLM со скиллом и kNN по эмбеддингам (frida, bge-m3) | 29–33% | 0,19–0,24 |

Две модели разных семейств выбирают один класс из 127 в 80% постов, а решение «есть класс / нет» у них совпадает в 95% случаев. Значит, правила скилла однозначны. **Эталонной разметки самого аналитика ZeBot для этих постов нет**, поэтому согласие моделей не доказывает, что классы выбраны так, как выбрал бы он.

## Ограничения

- **Словарь закрыт.** Новую формулировку модель не придумывает. Если в посте появилась мифологема, которой нет в `vocab.md` (проверено на синтетическом «Россия — яркий лидер»), пост получит `null`, и его не отличить от поста без класса.
- **Один класс на пост.** В реальном посте часто несколько классов, скилл берёт ведущий.
- **Теги «ложь», «манипуляция» и «реакция» не входят в словарь.** Их формулировки в канале почти не повторяются, а «реакция» относится ко всему посту, а не к цитате.
- Классы взяты из публичных постов канала ZeBot2050 и отражают взгляд его автора.
